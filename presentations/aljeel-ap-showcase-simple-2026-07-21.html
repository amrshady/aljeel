Supplier 1 · Asateel (transportation)

Sorting thousands of rides correctly

Asateel bills for transportation. The challenge: each ride has to be charged to the right team and budget — and some rides serve more than one team, so the cost has to be split fairly.

  • The system reads the full invoice and daily trip report automatically.
  • It checks each ride against AlJeel's official records to find the right team.
  • When a ride serves several teams, it splits the cost fairly between them.
  • It runs by itself the moment finance approves — no manual start.
